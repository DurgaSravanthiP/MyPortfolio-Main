## ✨ Features

- **Dynamic Typography:** Integrated [Typed.js](https://mattboldt.com/demos/typed-js/) for an engaging introduction.
- **Smooth Navigation:** Fixed header with smooth scroll behavior across sections.
- **Responsive Design:** Optimized for all devices (Mobile, Tablet, Desktop) using CSS Media Queries.
- **Interactive UI:** Hover effects, glassmorphism cards, and CSS animations (slide-ins) for a premium feel.
- **Comprehensive Showcase:** Sections for About, Services, Skills, Projects, and Contact.
